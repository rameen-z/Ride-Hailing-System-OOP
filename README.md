# 🚕 Ride Hailing System — C++ OOP Project

A **C++ Object-Oriented Programming semester project** that simulates a basic ride-hailing system. The project demonstrates core OOP concepts through different classes representing users, riders, drivers, rides, ride types, and distance calculation.

## 📌 Project Overview

This project was developed as part of the **Object-Oriented Programming (OOP)** course during the **2nd semester**.

The system models the basic workflow of a ride-hailing application, including users, riders, drivers, rides, ride types, fares, and distance calculations.

## ✨ Features

* 👤 User management
* 🚗 Rider and Driver classes
* 🚕 Ride management
* 💰 Different ride types and pricing
* 📍 Distance calculation
* ⭐ Driver rating system
* 🧩 Object-Oriented class structure
* 🔗 Relationships between different classes

## 🧠 OOP Concepts Demonstrated

This project demonstrates several important C++ OOP concepts:

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/rameen-z/Ride-Hailing-System-OOP.git
```

2. Open the project in a C++ IDE such as **Visual Studio Code**, Code::Blocks, or Visual Studio.

3. Compile:

```bash
g++ "Main for Project.cpp" -o RideHailingSystem
```

4. Run the program:

```bash
./RideHailingSystem
```

> The exact compilation command may vary depending on your compiler and setup.
